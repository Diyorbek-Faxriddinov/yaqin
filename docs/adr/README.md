# Arxitektura qarorlari (ADR)

Har bir muhim qaror qisqa hujjat sifatida yoziladi: **kontekst → qaror → oqibatlar**. Qabul qilingan ADR oʻzgartirilmaydi — qaror oʻzgarsa, yangi ADR yoziladi va eskisi "Almashtirilgan" deb belgilanadi. Qaror kengaysa yoki amalda aniqlashsa — asl matn oʻzgarmaydi, oxiriga sanasi bilan "Yangilanish" boʻlimi qoʻshiladi va holatda belgilanadi.
